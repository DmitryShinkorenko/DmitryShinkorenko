- **Теория тестирования** — синхронизирована с последней версией международной сертификации ISTQB
- **Техники тест-дизайна** — на примерах и практике
- **Тестовая документация** — чек-листы, тест-кейсы, отчёты о дефекте
- **Системы управления тестированием** — Jira, Testrail, Youtrack, QASE
- **Тестирование веб-приложений** — DevTools, Perfect Pixel, Figma
- **Тестирование мобильных приложений** — Android Studio, Xcode, CharlesProxy, Fiddler, Proxyman
- **Работа с базами данных** — MySQL (реляционные) и MongoDB (нереляционные)
- **Тестирование API** — Postman и Swagger
- **Git, GitHub и bash** — контроль версий и командная строка
- **Основы CI/CD** — Jenkins и GitHub Actions
